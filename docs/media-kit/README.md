# Media Kit: Big Dog and Maggie

The official character and content system for Hanceville Entertainment and Shopping.

## Files in this folder

- **Big_Dog_and_Maggie_Complete_Media_Kit.pdf** — The master guide: character descriptions, brand colors, the complete catalog of 78 poses with ID codes, descriptions, and best uses, production rules for flyers, videos, reels, audio, and AI generation, the quality protection rules, and the full file inventory.
- **AI_Content_Creation_Playbook.pdf / .txt** — How content for the Facebook Page and this website is planned, built, approved, and published: the content pillars, where each kind of content lives, the workflow, and the fact and safety rules.
- **New_Pose_and_Cutout_Guide.pdf / .txt** — How to create a new pose, cut the character out cleanly, and name, check, and file it into the library. Includes the pose request template and the pose record template.
- **AI_Video_Creation_Guide.pdf / .txt** — The video template book: house specifications, the master video request template, and ready-made templates for business spotlights, directory welcomes, events, deals, closings, website section videos, and advertisements, plus the talking video rules and the pre-approval checklist.

## The standing rules

1. Big Dog and Maggie are locked in design. Maggie always keeps her purple bow and her purple collar with the gold heart tag.
2. Build only from the full quality master PNG pose files. Never build from a preview, a screenshot, or a social media copy, and never upscale.
3. Every fact in any content comes from a verified source. Nothing is invented.
4. Nothing publishes without the approval of Charles Adams, the only approver.
