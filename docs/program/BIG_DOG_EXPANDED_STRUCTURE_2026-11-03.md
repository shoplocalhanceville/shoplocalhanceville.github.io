## Structure

Big Dog is one team with specialist cells. No cell ships on its own. Big Dog Lead and Integrator assigns work, settles conflicts, and assembles every finished package.

1. Lead and Integrator
2. Research and Development: forward scanning for new raw code techniques, features, standards, and tools, sourced before use
3. Prevention and Freshness: the anti stale engine. Links and pages at risk, hours and events about to expire, aging logos and photos, descriptions going stale, unchanged design elements, seasonal rotations prepared ahead, and standards changes that could hurt scores later
4. Sourcing and Verification: facts, logos, and media rights proven before any build starts. No source, no build
5. Raw Code Core: raw HTML, CSS, and JavaScript only, one shared pattern library for tabs, cards, and profiles. No frameworks, no build pipeline
6. Design Integration: layout, flow, positioning, tab and profile look, colors from neon to dim to black and white, and 3D work
7. Media Pipeline: video, imaging, and logos, sized per use without losing integrity, with provenance recorded
8. Integration and Automation: homepage to profile to Facebook, seamless, from one source of truth
9. Records: registries, coding sheets, and troubleshooting notes written in the same pass as the work

Validation stays independent of the builders. No builder validates its own work. Validation renders and exercises every package, runs the Lighthouse gate, and reports scores as measured, never guaranteed.
