# Security Policy

Hanceville Entertainment and Shopping is a static community directory served by GitHub Pages. It has no logins, no user accounts, no payment forms, and it does not collect or store personal data from visitors.

## Reporting a problem

If you find a security issue, a broken or unsafe link, or a listing that points somewhere it should not, please tell us privately:

* Send a message to our Facebook Page: https://www.facebook.com/ShopLocalAlabama
* Or open a private security advisory on this repository (Security tab, then "Report a vulnerability").

Please include the page address and what you saw. We aim to reply within 7 days and to fix confirmed issues as quickly as we can. Please do not post details publicly until a fix is live.

## Scope

* Pages and files on https://shoplocalhanceville.github.io/
* The code in this repository

Outside websites that our listings link to are run by their owners; we will remove or correct a link that looks unsafe.

## How the site is protected

* HTTPS everywhere, with HSTS from GitHub Pages
* A Content Security Policy on every page
* No third party trackers or ad scripts; all scripts are served from this site
* No secrets, keys, or private data are kept in this repository
* Every change is tracked in Git, so any change can be rolled back
* An automated monitor checks the live site against the repository for unexpected changes

## Data and privacy

The site is read only. The only things saved are your own preferences (theme, language, and saved places), and they stay in your browser's local storage on your device.
